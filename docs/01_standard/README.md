# Standards Notes

Use this folder for reading notes from official standards and algorithm specifications.

Primary files:

- `fips203_notes.md` for ML-KEM.
- `kyber_round3_notes.md` for the CRYSTALS-Kyber Round 3 specification.
- `fips202_keccak_notes.md` for SHA-3 and SHAKE background needed by ML-KEM.

Do not copy long passages from standards PDFs. Summarize parameters, interfaces, algorithms, and implementation questions in your own words.
