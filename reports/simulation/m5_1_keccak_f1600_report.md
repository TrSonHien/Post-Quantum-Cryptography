# M5.1 Iterative Keccak-f[1600] Report

Command `timeout 180s ./sim/scripts/run_keccak_f1600_core.sh` passes 132 full
permutation vectors: zero, all-one, structured lane patterns, and 128
deterministic random states. Every result is independently generated by the
pure-Python 24-round model.

The test accepts start on edge E0, commits round 0 on E1, commits round 23 and
asserts `state_out/done` on E24. Measured start-to-done latency is therefore 24
rising-edge intervals under the project convention. Done is one cycle. Start
while busy sets error. Synchronous reset cancellation is checked at every round
position 0..23; no stale done appears and restart succeeds.

Structurally the core has one 1600-bit state register and one shared
combinational round. This is a functional baseline only. No synthesis, area,
timing closure, or Fmax claim is made.
