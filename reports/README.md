# Reports

Use this folder for curated simulation result reports during the current phase.

Active report folder:

- `simulation/` for unit, block, and system simulation summaries.
- `security/` for structural security-control reviews and limitations.

M9 academic release reports at this level record the repository audit,
elaboration/lint evidence, synthesis-environment blockers, bottleneck analysis,
and release verification.  They do not turn unavailable synthesis into a PPA
claim; raw tool logs and databases remain untracked.

Raw tool outputs should stay in the matching tool workspace unless promoted into a curated report.
